# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately using [GitHub's private vulnerability reporting](https://github.com/aip-tech/braid/security/advisories/new) for this repository, or contact **<!-- TODO: add a security contact email -->**.

Include as much detail as you can: the version affected, a description of the issue, and reproduction steps if possible. We'll acknowledge reports as soon as we can and follow up with a fix or mitigation timeline.

## Supported versions

braid is early-stage and pre-1.0 (not yet published to npm). Until a stable release, only the latest commit on `main` is supported.
